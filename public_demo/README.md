# ShareGuard Demo

ShareGuard 影像信任工作台是一个面向比赛评委、试点客户和投资人的公开展示仓库。它展示产品流程、业务场景、报告样式和 API 边界，不包含模型权重、训练数据、私有评测材料或核心推理实现。

## 展示定位

ShareGuard 不把 AI 图像鉴别做成一个孤立分数，而是把疑似 AI 生成或篡改影像转成可归档、可复核、可交付的风险报告。公开 Demo 聚焦三类场景：

- 媒体发布前核验：判断图片是否适合进入发布流程
- 品牌舆情澄清：把疑似伪造宣传图转成公关和法务可读的复核摘要
- 平台人工复核：为审核队列提供风险分流信号

## 公开与私有边界

公开仓库包含：

- 静态产品 Demo
- 示例报告和演示文案
- 公开 API 响应结构
- 部署说明和比赛展示材料

公开仓库不包含：

- 模型权重
- 训练数据和特征缓存
- 私有实验记录
- 核心推理服务实现
- 内部阈值、融合参数和路径信息

真实检测能力通过私有 API 或客户本地部署接入。公开页面只展示产品闭环，避免泄露核心技术资产。

## 建议演示顺序

1. 打开 `index.html`
2. 默认展示“品牌谣言澄清”案例
3. 先讲“建议暂缓公开使用，进入人工复核”
4. 再展示传播链路视图
5. 最后展示报告导出和 API 接入方式
